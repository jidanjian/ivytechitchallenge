# ivytechitchallenge

Problem Statement: Staff member at this university need a quick and effective way of getting policy and procedure explained to them in plain text. This help improve productivity for the staff as they spend less time looking over all the document.

Solution: We will use a chatbot to generate a response to the policy base on the user's need and inputs. The chatbot will pull from a list data file with all of the policy and base on that it will respond to the user by telling what is the information in plain text. 

The Approach: After we figure out what do we as a solution to the problem we are able to ask the AI to give use a better overview of the entire data.

The pillar we serve: We focus on innovating and getting a more efficient way of finding information using new technology. 

IBM Bob usage: We use IBM Bob to generate us a version of the solution in a HTML file that run locally on our computers. We are able to revise the answer and get a working prototype.
